# 口袋直传

双方安装支持 API 2 的新版主程序和 `peer-1.0.0.zip` 扩展。在道具库的扩展管理中安装 zip，搜索“直传”打开。

1. 每次打开生成随机动物头像和昵称，支持在 **IPv6 直连** 与 **打洞穿透** 两种模式间切换：
   - **IPv6 直连**：自动筛选首选公网 IPv6 地址。A 输入 B 的 IPv6 地址（不带端口）发起连接，B 的窗口显示请求。
   - **打洞穿透**：自动采集公网 IPv6、局域网与 STUN 公网 IPv4 候选并生成 `PK2...` 口令（可选开启提取码使用 AES-256-GCM 加密）。双方互换口令并在 60 秒内各自点击“开始打洞连接”，打通 QUIC/TLS 1.3 通道后同样进入确认流程。
2. 收到请求的一方点击“同意连接”后看到三个随机数字，发起方看到一个数字。通过电话或当面核对，点击一致的数字。选错立即断开，验证两分钟后失效。
3. 验证成功后，双方均可拖拽文件到窗口或点击“选择文件”。支持多文件队列、双向同时传输，暂不支持目录。
4. 传输时展示进度、平均速度、字节数和动画；完成后可在“传输记录”查看并打开所在文件夹。

默认接收到系统下载目录下的 `Pocket Transfers`，可更改。遇到同名文件自动添加序号，不覆盖原文件。
传输记录保存在本机，保留最近 200 条已结束任务；进行中的任务不被裁剪。关闭窗口后重新打开仍可查看记录。

传输中会拦截正常退出、关闭传输窗口，以及停用、卸载或升级扩展。可以主动“取消传输”再退出；取消会断开连接并清理未完成文件。
系统强制结束进程、断电无法拦截；重启后将未结束记录标记为中断并清理临时文件。暂不支持断点续传，需要重新发送。

## 网络条件

- **IPv6 直连模式**：双方都必须有公网 IPv6，且系统和路由器防火墙允许 TCP **47831** 入站。仅有 `fe80::` 链路本地地址、`fc00::/7` 私网地址或 IPv4 无法使用直连。
- **打洞穿透模式**：通过 UDP/QUIC 同时向对方发送带一次性口令 HMAC 校验的探测包，可穿透常见 IPv6 防火墙与锥形 NAT（并通过公共 STUN 探测 IPv4 映射地址与 NAT 类型）。若双方均处于对称型 NAT 且无共同可用的 IPv6/局域网路径，仍可能无法打洞直连。
- 地址检测不保证外部可达；超时请检查对方扩展状态以及运营商和防火墙设置。本插件不自动更改防火墙，不使用中转服务器。
- 一个实例同时连接一位对方；直连固定端口 `47831` 不能被另一实例占用。

连接使用 TLS 1.3；配对数字由当前 TLS 通道派生，正确数字不通过协议发送，需双方通过可信渠道核对。
配对成功前拒绝所有文件数据。文件传输后使用 SHA-256 校验；接收端先写临时文件，完整校验后才发布为最终文件。
同意并验证意味着允许对方在本次连接中发送文件，收到的文件不会自动执行。
